# OpenClaw C.O.R.E.

> **OpenClaw C.O.R.E.** = **C**ontrol, **O**rchestration, **R**untime, **E**ngine

A tech-forward Linux brand built for both a polished web console and a fast, scriptable CLI.

---

## Recommended New Name

### Primary brand
**OpenClaw C.O.R.E.**

### Why this is better than Kernel/Kernal Cat
- **Original + ownable**: avoids sounding like a typo/variant of “kernel.”
- **Mascot-ready**: “Claw” supports a clean crab/agent identity (similar energy to Rust’s Ferris without copying).
- **Technical signal**: “C.O.R.E.” sounds infrastructure-grade and modern.
- **Web + CLI friendly**: looks good in a nav bar and abbreviates cleanly in terminal workflows.

### Tagline
**AI-Native Linux Control Plane**

## Product Identity

### CLI namespace
```bash
clawctl
```

### Example commands
```bash
clawctl status
clawctl doctor
clawctl node list
clawctl workflow run patch-cycle
clawctl ai assist "summarize failing services"
```

### Web ↔ CLI parity model
| Web UI Action | CLI Equivalent |
|---|---|
| Apply updates | `clawctl system update` |
| Restart service | `clawctl service restart <name>` |
| Node health | `clawctl health check` |
| Activity stream | `clawctl logs tail` |
| Edit policy/config | `clawctl config edit` |

## Voice and Tone

- **Direct**: “Update started on 8 nodes.”
- **Operational**: “Policy validated. 2 nodes require reboot.”
- **Actionable**: “Run `clawctl doctor --fix` to apply suggested remediations.”

Avoid generic phrases like “Something went wrong.” Always include the next best action.
